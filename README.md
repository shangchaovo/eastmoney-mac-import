# 东方财富 Mac 自选股导入助手

这款非官方 Mac 工具把一份六位 A 股代码清单写入你自己的东方财富云端自选分组，重开客户端就能查看。

**先用仓库自带的示例预览。** 在项目目录运行下面的命令，核对分组名、有效代码总数和前 8 个代码。预览只读取本机文件，不向云端写入。

```bash
python3 import_watchlist.py --file stocks.txt
```

也可以双击 `Import.command` 预览同目录的 `stocks.txt`，或把自己的文本文件拖到它上面。Mac 客户端菜单里的「导入工具」接收的是另一类 `.zip` 文件。

## 准备自己的清单

使用 UTF-8 文本，每行一个代码，名称可省略。保留代码开头的零。

```text
# 我的观察名单
600519,贵州茅台
sz000001,平安银行
300750
```

脚本会去掉 `sh`、`sz` 等前缀，跳过注释、空行、重复代码及格式无效的行。预览显示的是格式检查结果，证券是否存在仍需自行核对。[示例文件](stocks.txt)

## 确认分组，再写入

写入需要 macOS、Python 3.9+ 和已登录本人账号的东方财富 Mac 客户端，无需第三方 Python 包。若终端无法读取客户端的沙盒登录文件，可在「系统设置 → 隐私与安全性 → 完全磁盘访问权限」授权给实际运行脚本的终端。登录信息只用于访问东方财富的云端自选接口，请勿公开登录信息或终端输出。

**同名组会被整组替换。** 默认组名是「导入月日」，同一天再次导入会命中同一组。想保留原清单，请选用新的组名，并避开默认「自选股」。同步请求还会排除名称以「导入临时」开头的旧组，有需要保留的组请先在客户端改名。预览不读取云端分组，无法列出本次会命中的旧组。

```bash
python3 import_watchlist.py --file stocks.txt --group-name 我的观察
python3 import_watchlist.py --file stocks.txt --group-name 我的观察 --apply
```

脚本回读目标组并核对股票数量，成功后输出 `done:` 以及组名和数量。此时重开东方财富查看结果；也可在写入命令末尾加 `--relaunch` 让脚本代为重启客户端。

## 兼容性与许可

这是第三方工具，与东方财富官方无关联。它依赖 Mac 客户端使用的接口，客户端或接口改版可能影响写入。Windows 客户端另有官方导入菜单。本工具仅整理自选名单，不提供投资建议。

离线自检可运行 `python3 import_watchlist.py --self-test`，检查代码格式转换及列表处理。项目采用 [MIT 许可证](LICENSE)。
